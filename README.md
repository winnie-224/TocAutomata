# TOC Studio – Interactive Automata Simulator

TOC Studio is a web-based learning tool for **Theory of Computation**.  
It allows users to define a **Deterministic Finite Automaton (DFA)** and:

- Simulate it on an input string
- View the result (Accepted / Rejected)
- See the **state transition table**
- Validate automaton definitions

Built using **ASP.NET Core Razor Pages**.

---

## Features

- Define DFA using simple text input
- Automatic validation of:
  - States
  - Start state
  - Final states
  - Transitions
- DFA simulation engine
- State transition table (formal δ function view)
- Error handling for invalid definitions
